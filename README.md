# Northstar College — Concept Website

A polished, responsive college/university landing page built with plain HTML, CSS, and JavaScript. No build tools or package installation are required.

## Preview locally

Open `index.html` in a browser, or use VS Code's Live Server extension.

## What's included

- Responsive navigation with mobile menu
- Admissions announcement and call-to-action links
- Hero section and college statistics
- Program cards, campus life section, student quote, and admissions CTA
- Responsive layouts for mobile, tablet, and desktop
- Accessible image descriptions and reduced-motion support

## Customize before publishing

This is a design concept, not an official college website. Replace the sample **Northstar College** branding, statistics, program details, images, and the `admissions@example.edu` email with verified college information. Photos are loaded from Unsplash and Google Fonts are loaded externally, so those resources require an internet connection.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript
